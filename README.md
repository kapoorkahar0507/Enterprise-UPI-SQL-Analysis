# Enterprise-UPI-SQL-Analysis
SQL Server project analyzing UPI Transactions using advanced SQL queries, window functions, CTEs, views, and  stored procedures.
# Project Objective
The objective of this project is to analyze UPI transaction data using Microsoft SQL Server to generate meaningful business insights and strengthen SQL skills through real-world business scenarios. The project involves importing cleaned data from Excel into SQL Server and  writing SQL queries to answer business questions.
